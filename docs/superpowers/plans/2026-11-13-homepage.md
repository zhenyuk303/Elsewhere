# ELSEWHERE Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the post-auth placeholder with a responsive, cinematic homepage that crossfades through all 34 existing province images every 10 seconds.

**Architecture:** Build a dedicated `HomePage` component with two persistent background layers. A 10-second timer alternates the active layer; after the opacity transition finishes, the hidden layer is repointed to the following slide so only two large images are mounted at once. Static navigation and editorial content sit above the layers, and `App` renders the page directly after the existing runway transition completes.

**Tech Stack:** React 19, TypeScript, CSS, Vitest, Testing Library, Vite

**Spec:** `docs/superpowers/specs/2026-11-13-homepage-design.md`

## Global Constraints

- Work only on branch `Homepage`; do not modify `main`.
- Reuse the 34 deterministic entries from `travelSlides`; do not shuffle or add assets.
- Rotate every 10,000 ms using opacity only; no slide, zoom, pan, or homepage entrance animation.
- Keep navigation, editorial copy, divider, and lower-left marker fixed.
- Render uppercase `<LOCATION>, CHINA` inside the same fading layer as its image.
- Mount exactly two scenic image layers to avoid eagerly loading the roughly 97 MB image collection.
- The homepage component must not call authentication or other backend APIs.
- Keep the existing system sans-serif font stack and all required text pure white.
- Navigation and profile affordances are static hooks with no click handlers and no hover animation.

## Review Focus

- A slow or very large next image: the current layer and fixed content remain visible; the layout never becomes blank.
- Timer boundaries: no image changes before 10,000 ms, and exactly one layer swap happens at each boundary.
- Repeated rotations: after each fade, the hidden slot advances to the correct following slide and the sequence wraps after slide 34.
- Unmount during a timer: the interval is cleared and cannot update an unmounted component.
- Reduced-motion users: rotation cadence remains 10 seconds while opacity transition duration becomes near-instant.
