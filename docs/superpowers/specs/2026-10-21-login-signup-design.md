# Elsewhere 注册 / 登录 Demo 设计

## 目标

在空白的 Elsewhere 仓库中创建一个现代、极简、具有旅行氛围的前端 Demo。默认显示注册页，用户可以在注册页与登录页之间切换；右侧旅行图片轮播保持连续运行。点击表单主按钮时，按钮通过液态形变转化为黑色飞机跑道，白色飞机沿页面中轴飞出，随后展示主页占位。

本项目只实现前端 UI、交互动画和页面状态，不包含后端、真实接口或数据库。

## 技术方案

- React + TypeScript + Vite
- React 负责页面模式、轮播阶段、表单校验和转场状态
- CSS 动画负责布局切换、轮播滑动、蒙版运动、跑道透视和飞机飞行
- SVG Gooey Filter 负责 Login 按钮到跑道之间的液态黏连质感
- SVG 裁切路径负责彩色图片的旋转圆角正方形蒙版
- 不引入通用动画库或 Canvas/WebGL，保持依赖轻量且便于维护

## 应用结构

### App

顶层组件维护以下状态：

- `authMode`: `signup` 或 `login`
- `view`: `auth`、`transitioning` 或 `home`
- `transitionOrigin`: 保存主按钮的位置，供全屏转场定位使用

`signup` 与 `login` 之间的切换只影响左侧内容。只有主按钮提交成功后才进入 `transitioning`，动画结束后进入 `home`。

### AuthPanel

左侧表单区域。注册与登录共享输入框、密码显隐控件和主按钮，仅根据 `authMode` 改变标题、说明、条款、第三方入口和底部链接。

注册模式包含：

- 品牌名 `ELSEWHERE`
- 标题 `Create your account`
- 副标题 `Let's create an account and start a wonderful journey`
- Username
- Password 及显隐按钮
- 条款复选框 `I agree to all Term, Privacy Policy and Fees`
- 主按钮 `Login`
- `Or sign up with`
- QQ、微信入口
- `Already have an account? Login`

登录模式包含：

- 品牌名 `ELSEWHERE`
- 标题 `A wonderful journey begins now.`
- Username
- Password 及显隐按钮
- 主按钮 `Login`
- `Don't have an account? Sign up`

底部链接切换模式时，左侧内容做轻微水平移动或内容替换。右侧轮播组件保持挂载，当前图片、动画阶段和计时不会重置。

### TravelCarousel

右侧组件使用可替换的图片数据数组，每项包含图片地址与地名。画面只显示地名，不显示套餐、国家或其他说明文字。

每一张图片由两层同源图像组成：

- 底层始终为灰度图
- 上层为彩色图，通过 SVG 圆角矩形裁切显示

彩色裁切框从画面中心开始，持续 2.5 秒逆时针旋转并扩大至图片区域宽度约 70%。白色边框约 5px，与裁切框同步运动。动画完成后，画面完全静止 3 秒。

停留结束后，当前图片向左滑出，下一张灰度图片从右侧滑入，换图持续 1.2 秒。不使用淡入淡出，不出现透明或白屏。滑动完成后，新图片从头执行蒙版动画。

单张图片的正常周期为：

1. 蒙版扩大与旋转：2.5 秒
2. 彩色画面静止：3 秒
3. 水平滑动换图：1.2 秒

总周期为 6.7 秒。主按钮转场开始时暂停轮播计时与视觉运动。

### RunwayTransition

转场组件为全屏覆盖层，只在主按钮提交通过后挂载。

动画阶段：

1. 读取 Login 按钮的屏幕位置，将黑色液态形状放置在按钮上方。
2. 按钮文字缩小、模糊并消失；按钮主体通过 SVG 黏连滤镜产生柔软的拉伸形变。
3. 黑色形状向左右栏分割线延伸并与中轴融合，形成纵向黑色跑道。
4. 跑道从上向下产生透视拉伸，白色简约飞机剪影从跑道前端形成。
5. 飞机沿中轴从上向下加速飞出；左右内容同时向两侧及下方退出画面。
6. 跑道和旧页面离场后，挂载主页占位并移除转场层。

飞机采用项目内联 SVG，轮廓参考提供的白色简约飞机剪影，不使用参考图本身作为资产，也不加入纹理。

动画期间锁定主按钮，阻止重复提交或重复启动转场。

### HomePlaceholder

主页仅作为转场目标，显示 `ELSEWHERE` 和简短的旅程开始提示。组件边界保留给后续真实主页替换，不实现其他业务功能。

## 表单行为与校验

- Username 和 Password 均为必填
- 注册模式必须勾选同意条款
- 校验错误显示在对应输入区域附近，不调用任何接口
- Password 显隐按钮切换输入类型，并提供可访问名称
- 用户按 Enter 时执行与主按钮相同的校验和提交逻辑
- 校验失败不触发飞机跑道动画
- QQ 与微信入口只提供视觉与按压反馈，不执行真实授权

## 响应式设计

- 桌面端保持左右双栏，表单与轮播之间有清晰的竖向中轴线
- 窄屏端改为上下排列，表单在上，轮播在下并降低高度
- 窄屏转场以两块区域的水平交界位置为起点，将跑道调整为适合视口的纵向运动路径
- 输入框、按钮、圆角、间距和字体比例在各断点保持一致的设计语言

## 无障碍与降级

- 所有表单元素都有可访问标签
- 密码显隐和底部模式链接支持键盘操作与可见焦点
- 使用语义化表单和按钮
- 当系统启用 `prefers-reduced-motion` 时，大幅缩短轮播与转场时长，避免旋转和剧烈位移，但仍完成相同的页面状态切换
- 图片加载失败时显示不破坏布局的中性色背景和对应地名

## 测试与验收

自动化测试覆盖：

- 默认打开注册页
- 注册与登录模式只显示 Username 和 Password
- 密码显隐功能
- 注册条款校验及必填校验
- 底部链接只切换左侧表单，不重置右侧轮播
- 轮播阶段顺序与 2.5 秒、3 秒、1.2 秒时序
- 主按钮校验成功后启动转场，失败时不启动
- 转场期间暂停轮播并防止重复提交
- 转场结束后挂载主页占位

开发完成后执行：

- 单元与组件测试
- TypeScript 检查
- 生产构建
- 桌面和移动视口的浏览器视觉检查
- 动画过程检查，确认无闪白、无意外淡入淡出、无遮挡或布局跳动

## 明确不做

- 后端、数据库和真实认证
- Email 输入框
- Google 或 Facebook 登录
- 旅行套餐说明文字
- 真实 QQ / 微信授权
- 主页业务内容
- Canvas/WebGL 物理流体模拟
