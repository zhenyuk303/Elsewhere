# Elsewhere 圆形拉伸飞机转场设计

## 目标与范围

在现有 Elsewhere 注册 / 登录 Demo 中，仅替换点击主 `Login` 按钮后的转场效果。保留当前注册与登录文案、表单行为、右侧轮播、底部账号切换方式、主页占位以及现有双栏卡片布局。

新转场严格串行执行：按钮收缩为黑圆、黑圆水平移动到双栏分割线、黑圆沿分割线同步向上和向下拉伸、底部白点变为飞机、飞机向上飞行并擦除旧页面，最后挂载主页占位。

本功能不包含后端、接口、数据库、真实登录或主页业务 UI。

## 方案选择

### 采用：React 阶段状态机 + CSS 几何动画

React 只负责五个离散阶段和完成回调，CSS 负责位置、尺寸、形变和擦除。按钮的实际屏幕矩形继续由表单提交时读取；卡片及分割线几何信息在转场挂载时由 DOM 测量获得，并通过 CSS 自定义属性传入动画层。

这个方案最适合现有代码结构：不新增动画库，阶段可测试，布局变化后仍能精准对齐真实卡片和分割线。

### 未采用：单条 CSS keyframes 时间轴

单条时间轴代码较短，但阶段边界难以测试，且按钮、分割线、卡片高度都依赖运行时几何信息，维护时容易发生关键帧错位。

### 未采用：Canvas / WebGL

Canvas 可以实现复杂遮罩，但会增加重绘和响应式定位成本，也不利于无障碍与组件测试。当前效果由普通 DOM、SVG 和 CSS 即可完成。

## 保留行为

- 默认打开注册页。
- 注册与登录页现有标题、副标题、输入框、条款显示规则和第三方入口保持不变。
- 底部 `Login` / `Sign up` 链接只切换左侧内容，不触发飞机转场，也不重置右侧轮播。
- 右侧轮播继续使用 5px 白色圆角正方形边框；框内对应像素恢复彩色，框外保持灰色。
- 轮播继续按 2.5 秒蒙版动画、3 秒静止、1.2 秒左右滑动换图循环。
- 转场开始后轮播暂停；转场结束后直接进入主页占位，因此认证页轮播卸载。
- 表单校验失败时不启动转场；转场期间阻止重复提交。

## 几何数据

`TransitionOrigin` 扩展为本次动画需要的布局快照：

- `left`、`top`、`width`、`height`：主按钮的视口矩形。
- `dividerX`：桌面双栏分割线的视口横坐标；取右侧轮播区域的 `left`。
- `cardTop`、`cardHeight`：双栏卡片的视口顶部和高度。

`App` 通过 `journey-card` 引用读取卡片几何信息。提交时把按钮矩形与卡片矩形合并成不可变快照，避免动画过程中再次布局测量。

窄屏布局没有垂直双栏分割线时，`dividerX` 使用卡片水平中心，使动画仍沿视口中轴运行。

## 动画阶段与时序

总时长为 3000ms，各阶段前一段完成后才进入下一段：

1. `collapse`，0–450ms：覆盖在原按钮位置的黑色形状从按钮尺寸收缩为直径等于按钮高度的正圆。`Login` 文本同步缩小并变成黑圆中心的白色小圆点。
2. `dock`，450–1000ms：黑圆保持尺寸和垂直中心不变，仅沿水平方向移动，使圆心精确落在 `dividerX`。
3. `stretch`，1000–1700ms：黑圆以停靠点为中心，向上、向下同步拉伸为黑色竖条；上下边缘同时到达 `cardTop` 和 `cardTop + cardHeight`。竖条宽度为 44px。白点在此阶段沿竖条向下移动到底部的飞机停靠点。
4. `morph`，1700–1900ms：白点淡缩，同时白色飞机剪影放大出现，飞机机头朝上，中心与分割线重合，底部与卡片底端留出安全间距。
5. `flight`，1900–3000ms：飞机沿中轴由下向上加速飞出视口。飞机下机翼两侧延伸出两条与机翼边缘重合的斜线；两条线围成的浅色擦除面跟随飞机向上扩张，覆盖旧页面。擦除完成后调用 `onComplete`，由 `App` 挂载主页占位。

阶段缓动分别使用自然的收缩、水平停靠、同步拉伸和加速曲线。只有横向移动阶段改变黑圆的 `left`；其垂直中心保持不变。

## 图层结构

全屏转场层使用以下可测试元素：

- `transition-shape`：按钮、黑圆和黑色竖条的同一视觉主体。
- `transition-dot`：由按钮文字收缩而来的白点。
- `transition-airplane`：内联 SVG 白色飞机剪影，机头朝上。
- `wing-guide wing-guide--left/right`：两条与下机翼边缘一致的辅助线。
- `page-wipe`：页面背景色擦除面，位于飞机之下、旧页面之上。

旧页面本身不移动、不缩放、不透明度淡出。黑色竖条和擦除层均叠加在旧页面之上，因此左侧表单与右侧轮播的布局不受动画影响。

## 状态与组件接口

`TransitionStage` 改为：

```ts
type TransitionStage = 'collapse' | 'dock' | 'stretch' | 'morph' | 'flight'
```

`RunwayTransition` 保留现有公开接口：

```ts
type RunwayTransitionProps = {
  origin: TransitionOrigin
  onComplete: () => void
}
```

组件内部根据固定阶段边界更新 `data-stage`。卸载时清理所有计时器；完成回调最多调用一次。

## 降级与响应式

- `prefers-reduced-motion: reduce` 时保留相同阶段顺序，但把总时长压缩为 150ms，并取消大幅缩放与加速运动。
- 桌面端以真实双栏分割线为中轴。
- 小于 880px 的上下布局以卡片水平中心为中轴，竖条仍覆盖卡片高度。
- 动画层 `pointer-events: none`，避免遮罩期间出现意外交互。

## 测试与验收

自动化测试覆盖：

- 初始阶段为 `collapse`，并正确写入按钮、分割线和卡片几何 CSS 变量。
- 450ms、1000ms、1700ms、1900ms 时依次进入 `dock`、`stretch`、`morph`、`flight`。
- 3000ms 时只调用一次完成回调。
- reduced-motion 路径仍按同一阶段顺序并完成。
- 转场包含黑色主体、白点、飞机、两条机翼辅助线和擦除面。
- App 提交后只挂载一个转场、暂停轮播、保留旧页面静止，并在完成后挂载主页占位。
- 底部模式链接仍不会启动转场或重置轮播。
